# Hello World in Python

This is a beginner-friendly Python project for the `hello-world` repository.

## What it does

The script prints a simple greeting to the console.

## Run it

```bash
python hello.py
```

## Expected output

```bash
Hello, World!
```

## Learning goal

This project helps beginners understand:
- how to write a Python script
- how to run Python code
- how to use the `print()` function
